# W RYTMIE / Wemanapp

Lokalna wersja aplikacji React + TypeScript + Vite.

## Uruchomienie na Windowsie

```powershell
npm.cmd install
npm.cmd run dev
```

Terminal wyświetli lokalny adres aplikacji, zwykle `http://localhost:5173`.

## Struktura

- `src/components/w-rytmie` — główne ekrany aplikacji
- `src/components/ui` — formularze, suwaki i zakładki
- `src/lib/w-rytmie` — obliczenia, dane i zapis lokalny
- `src/index.css` — fioletowy wygląd aplikacji
